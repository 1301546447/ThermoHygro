# 中文报表字体

`ThermoHygroSans-Regular.ttf` 随报表程序集嵌入，用于中文 PDF，按 SIL Open Font License 1.1 分发。完整许可证见 [OFL.txt](OFL.txt)。应用自己的 MIT 许可证不改变字体的许可证。

来源为 [Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 的 `NotoSansSC[wght].ttf`，来源 Git 文件编号为 `fb0637bafbcd804fe32152370a1225990745b4bc`。原文件 17,772,300 字节。

本项目用 fontTools 4.66.1 将字重固定为 400，并将修改后字体的名称改为 ThermoHygro Sans，保留原版权声明及中文字符映射。字体只用于程序生成的报表，无需安装到 Windows 系统中。
