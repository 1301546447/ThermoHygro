## 已覆盖的行为

同一串口只打开一次，按地址收发；不同串口可以并行。名称、位置和地址修改后编号不变，历史持续归属原设备。重复地址或不一致的总线参数在保存时拦截；停用或移除配置不会删除历史。

所有失败的采集轮次也记录尝试及缺测，空值不当作零。各传感器维护独立阈值版本。屏幕查询、CSV 和 PDF 根据相同查询快照导出；后台先取得界面选项，再进行数据库工作。按本机午夜分桶，停采时段也明确计入缺测与覆盖率，曲线不跨过空白时段。

SQL Server 旧库阈值编号兼容升级到 64 位；名称、阈值、样本、分钟和事件均可同步。较长数据库名称使用固定长度目标编号并保留可读说明。已确认的数据在重放时不会重复新增；更新中的分钟继续保留待传状态。

首次向导完成后刷新真正使用的配置和本地库。窗口关闭后留在托盘，可重新显示；退出释放采集、串口及存储。登录启动路径在启动新版本时更新；Windows 禁用启动项会记录说明，不伪装成已经启动。

## 部署与边界

应部署完整 `ThermoHygro-0.5.0-win-x64` 目录。保留原用户数据目录，SQLite 不需执行额外 SQL。使用已有 SQL Server 同步库时，备份后在正确库中执行 `database/sqlserver/002_multi_sensor_thresholds.sql`，脚本可重复运行、适配 Navicat 的批次格式。
