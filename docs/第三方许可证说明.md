## 中文字体

程序内置 ThermoHygro Sans 常规中文字型，从 Google Fonts 的 Noto Sans SC 固定字重 400 并改名生成，按 **SIL Open Font License 1.1** 分发。原字体版权属于 Adobe 等原作者，不适用本项目自己的 MIT 许可证。

完整许可和来源见 `assets/fonts/OFL.txt`、`assets/fonts/README.md`；发布包放在 `ThirdPartyNotices/ThermoHygroSans/`。字体已嵌入报表程序集，不需要安装系统字体。字体许可允许随软件分发，但不能把字体本身作为单独商品出售；修改版使用独立名称，并保留原版权及许可。

## 已执行的依赖检查

本次先前发现 System.Security.Cryptography.Pkcs 9.0.18 存在公开安全通告，现已显式更新为 10.0.13。更新后运行 `dotnet list ThermoHygro.sln package --vulnerable --include-transitive --format json`，已知漏洞项为 0。该结论对应检查日期，不代表未来不会出现新通告。
