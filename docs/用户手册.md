# 用户手册

适用版本：0.5.0。运行环境：Windows x64。首次使用推荐只选择“本机保存”。

## 首次连接

解压免安装包到固定目录，双击 `ThermoHygro.exe`。向导会依次完成型号、串口、测试读取、保存方式、名称位置和上下限设置。

串口默认 9600、8 位数据、无校验、1 位停止位，地址默认 1。参数必须与实物一致。“测试读取”分别展示温度和湿度；打开串口成功不等于读到了传感器数据。

传感器采用 RS-485 串口通信，电脑通常需要 USB 转 RS-485 转接器。没有端口时先检查驱动，必要时刷新串口列表或手动输入端口名称。

完成向导后点击“开始记录”。本机数据库自动初始化，无需 SQL Server 或一体机程序。

## 多个传感器

在“设备与串口”选择“增加传感器”，程序会建立尚未启用的草稿，并选择当前串口未占用的地址。填写名称、位置、串口和实物地址，勾选“启用当前传感器”，再点击“保存设备信息”或“保存设置”。

同一条 RS-485 线路上的传感器使用不同地址，并共用波特率、数据位、校验位和停止位。不同串口可以使用相同地址。名称应有区分，例如“冷藏区”“室内”“药库”。

**地址字段只决定软件向谁读取。** 若两台实物都使用地址 1，必须先通过厂家的方法将其中一台改为地址 2；只改软件配置不会改变实物地址。

维护页与实时页的选择框同步。切换后显示当前传感器参数和读数，其他已启用的传感器继续采集。未保存的输入不会自动应用到设备。

运行中保存设置时，程序先保留新配置、停止旧采集并释放端口，再用新配置重新采集。连接失败会显示原因并重试。“恢复上次可用配置”同时恢复保存文件和采集参数。

修改名称、位置或地址不会改变固定编号，因此历史不会因为改名而断开。真正更换实物时使用“更换实物，建立新编号”，使新旧传感器数据保持各自归属。

取消启用后保存，可暂时停用一个点位。停用全部点位会停止采集。“移除当前传感器”保留原数据库记录，可在历史设备中继续查询；至少保留一个配置。

## 上下限与缺测

在维护页下方为当前传感器分别填写温度、湿度上下限，点击“保存当前传感器上下限”。留空表示不启用对应边界；等于边界算正常。湿度上下限范围为 0～100%。

新上下限只影响后续采集，旧阈值和超限次数保持原样。读不到的数据不会用旧值或 0 填补，实时页显示缺测，历史保留实际尝试次数。

同串口请求按顺序处理。点位较多、单台无回复或超时设置较长时，实际周期会超过设定间隔；可以适当调整超时、间隔或分配更多串口。

## 历史报表

选择传感器，再选择今天、本月、近 7/30 天或“自定义日期”。自定义范围包含结束日。旧设备和已移除点位会标为“历史设备”。

“查询”显示均值、极值、有效次数、缺测、覆盖率和事件。统计按有效次数加权，缺测不算作零。一天内使用分钟汇总，2～31 天使用小时汇总，更长范围使用每日汇总。

“导出 CSV”生成汇总、事件两张表，采用带标记的 UTF-8 编码，中文 Excel 可直接打开。文本列会防止被 Excel 当成公式执行。

“导出 PDF”生成中文统计和曲线报表。单点也会标出读数和时间；缺测不伪装成正常曲线。程序包含开放许可的中文报表字体，无需另外安装。

报表默认存入 `%LocalAppData%\ThermoHygro\Exports`。

## 保存、备份和可选同步

默认本地数据库为 `%LocalAppData%\ThermoHygro\Data\history.db`，所在目录需要可写权限。逐次样本保留 7 天，分钟汇总持续保留。

使用“备份本地库”进行在线备份，不能在运行中只复制 `history.db` 而忽略其写入日志。“验证备份”会检查结构和记录数量。恢复现有本机库时，先在界面验证备份，退出程序并保留原数据库目录的完整副本。默认路径可将原 Data 目录改名留存，新建 Data 后将验证过的备份复制为 history.db，再启动复核记录；自定义保存路径应由维护人员按实际路径恢复，不能在运行中直接覆盖数据库。

只有需要集中汇总时才选择“同时保存到 SQL Server”。本机始终先存，远端失败不会中断本机记录。服务器和数据库需要先用发布包 `database/sqlserver` 中的脚本初始化。

Windows 身份验证不需要保存密码。SQL 用户名密码的密码仅在当前进程保留；重启后需重新填写并应用存储设置，填好前本机仍持续保存。

## 托盘、悬浮和登录启动

关闭主窗口会隐藏到托盘，采集继续。托盘图标可以重新打开窗口、暂停、切换悬浮或退出。真正退出才释放串口和本地库。

悬浮窗显示实时页选中的传感器，可设置四角、显示器、字号、颜色和鼠标穿透。暂停、失败或过期读数显示缺测。

“登录 Windows 启动”和“启动后自动开始采集”是两项独立设置。需要登录后自动记录时应同时开启，并把程序解压到固定目录。若任务管理器禁用了启动项，需要在“启动应用”中启用，再重新登录验证。

## 从 0.4 升级

1. 退出旧程序并备份本机数据库。
2. 将 0.5.0 完整目录解压到固定位置，运行新的 `ThermoHygro.exe`；不要混用旧 DLL。
3. 旧单传感器配置会迁移为列表中的第一个传感器，固定编号、名称、地址和历史保留。
4. 使用本机 SQLite 时不需要额外运行升级 SQL。
5. 使用既有 SQL Server 同步库时，先在 Navicat 中选中正确的工具数据库，备份后执行 `002_multi_sensor_thresholds.sql`。脚本可以重复执行，不删除表或清空数据。
6. 检查登录启动和自动采集设置，并在现场实际读取各传感器验收。

默认用户数据目录独立于程序目录，更新程序不会清除数据。通过 `THERMOHYGRO_HOME` 设置了其他目录时，升级后继续使用相同设置。
