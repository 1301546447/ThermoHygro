# 0.5.0 更新说明

日期：2026-10-14。

增加可维护的多传感器列表，各点位独立名称、位置、串口、地址、启用状态和上下限。同一串口只有一个收发拥有者，不同串口可同时采集。改名、改地址不改变固定编号；移除配置后仍可查询原历史。

实时页增加全部传感器状态，历史页增加设备选择与自定义日期。首个传感器的旧配置自动迁移。首次向导完成后会刷新真正使用的主界面和存储路径。

修复整轮失败不记录缺测、后台查询跨线程访问、显示器列表类型错误、阈值版本号截断、远端名称与阈值漏同步、远端缺测变成零以及较长同步目标名称导致的失败。报表单点可见，曲线标题与页头分开，补充时间刻度和页码；程序提供开放许可的中文字体。修复依赖漏洞检查识别到的加密组件安全通告。

新增公开仓库使用的 MIT 许可证、构建发布脚本、验证入口和上传文件清单。现场配置、数据、日志、备份、内部来源资料和生成的程序包均不纳入源码提交。

部署应替换小工具的完整 0.5.0 程序目录。原用户数据目录保留。SQLite 自动兼容原库；已有 SQL Server 同步库另执行 `database/sqlserver/002_multi_sensor_thresholds.sql`。一体机工程不需跟随部署本次小工具更新。
